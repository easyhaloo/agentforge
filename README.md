# AgentForge

**Agent-native Source Control & Verified Change Platform** — interactive React prototype.

## Stack

- React 19 + TypeScript + Vite
- Recharts + Lucide React
- Responsive dark UI with local demo state

## Run locally

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## Product areas

Overview, Projects, Repositories, Changesets, Workspaces, Trails, Stacks, Review, Eval, Self-healing, Memory, CI/CD, Security, Governance, Cost & Usage, Settings.

## Prototype interactions

- Navigate all 16 product areas from the sidebar.
- Search and jump between areas with the command palette (⌘K).
- Create demo resources, filter changesets and inspect a selected changeset.
- Explore dashboard metrics, activity stream and verification status.
- Responsive desktop, tablet and mobile layout.

## Important limitation

This is a frontend-only prototype backed by local mock data. It does not perform real Git operations, create remote branches, execute agent sessions, run CI, evaluate changes, enforce security policies, or persist changes to a backend. All such integrations remain future work.
