Overview

The API Server is the core component of the AgentForge platform. It provides:

  • RESTful API endpoints for all platform operations
  • JWT-based authentication and authorization
  • WebSocket support for real-time updates
  • Background job processing with worker pools
  • PostgreSQL database integration

Architecture

The server follows a layered architecture with clear separation of concerns:

  • cmd/ - Application entry points
  • internal/auth/ - Authentication and authorization
  • internal/worker/ - Background job processing
  • internal/api/ - HTTP handlers and routing
  • internal/db/ - Database access layer
