# AgentForge 工作区导航原型

在浏览器打开同目录的 `index.html`。原型采用 AgentForge 浅色主题，参考用户截图中的工作台三栏、全局导航抽屉和 GitHub 的页内标签。两个组织及其仓库、评审和运行记录使用示例数据。新建流水线、参数编辑和模拟执行保留在当前浏览器页面会话，刷新后恢复样例。

| 页面 | 对应项目功能 | 验证路径 |
| --- | --- | --- |
| 工作台 | 总览、变更集及评审 | 切换「待我评审」和「我发起的」。打开评审再切到北辰实验室，应返回该组织的评审列表。浏览器后退应恢复原变更及修订。 |
| 仓库 | 仓库详情、文件浏览、WebIDE | 「代码」「变更集」「流水线」按仓库展示。打开 `src/index.ts` 后刷新，仓库、提交和文件路径应保留。 |
| 流水线 | 定义列表、编辑画布、运行参数、执行详情 | 右上角创建 → 点击画布阶段 → 更改默认参数 → 运行。弹窗应读取配置，执行页应显示实际选择的参数。 |
| 组织设置 | 成员、邀请、成员审计 | 从组织选择器或抽屉进入。星河研发为管理员视图，北辰实验室为成员视图。 |

原型范围聚焦上述页面。任务入口以项目现有的变更集与评审为基础。仓库 Issues、项目、工作空间、安全和治理由各自模块后续承接。

从仓库根目录运行 `node docs/_archive/prototype/workspace-navigation/verify.cjs` 可复验上述路径。追加截图输出目录可保存浏览器截图。
